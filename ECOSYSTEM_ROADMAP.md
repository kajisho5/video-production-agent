# Roadmap — video-production-agent

Part of the [AI Video Production OS](https://github.com/kajisho5/AI-video-production-OS/blob/main/docs/ecosystem/ROADMAP.md) ecosystem: department **司令塔 (Command)**, status `active`.
Written from a read-only audit of this repository on 2026-10-30. Each step below is meant to be one pull request; tick it off by linking the PR.

## Where it stands

Python orchestrator (`video-agent`). 22 adapters (ffmpeg-skill, video-editing, audio-production, color-grading, motion-graphics, subtitle, thumbnail, qc, media-analysis, transcription, ingest, voice-enhance, imagemagick-skill, dubbing, diarization, publish, nle-bridge, detection, slide-sync, sound-design, remotion-ffmpeg-skill, artifacts-skill). Brain: deterministic rules + optional AI (Claude API, ADR-049; the chat model through MCP, ADR-050). Handoffs for steps no installed skill can run (ADR-051). 405 unit + 53 integration tests.

## What this repository owns

`ecosystem.json` gives each job to exactly one repository. Work outside this list belongs to its owner and is handed over, not re-implemented.

| Owned job | Status | Note |
|---|---|---|
| 制作計画 | done | plan / revise / approve / render |
| スキルの呼び分け | partial | every ecosystem job has a SkillSpec, so a handoff names its package (ADR-057); 15 of them have no adapter yet (step 9; ingest has one, ADR-066; voice-enhance, ADR-073; dubbing's DUB, ADR-085); imagemagick-skill prepares overlay images (ADR-077) while `still_image_edit` stays a handoff |
| 制作記録(ProductionReceipt) | done | ADR-040 |

## Wiring

Uses 17 of ffmpeg-skill's 42 tools directly (3.x, contract_version 2.0 read like 1.0, ADR-082) through a hand-maintained catalog (19 entries; fit, report unreachable; scenes for `--beats` only, ADR-053). Reads ffmpeg-skill's `_contract.py --json --static` and `doctor --json` at locate time to check the catalog (ADR-056). NLE interchange (OTIO / FCPXML / EDL) through ffmpeg-skill `render --export-timeline` (ADR-052). ingest-skill pinned at 0.1.0 (card offload, ADR-066); voice-enhance-skill pinned from main at 0.1.0 (no release tag; isolate / dereverb / bleed-reduce on the audio path, ADR-073); imagemagick-skill pinned at 0.8.1 (resize / pad / strip of `edit.overlay` images, vocabulary read from the pin, ADR-077); qc-skill pinned at 0.2.6 (ADR-078; subtitle 0.4.0, transcription 0.8.0, thumbnail 0.1.7, media-analysis 0.1.7, motion-graphics 0.2.7, video-editing 0.4.1 in the same re-pin); its opt-in VMAF / SSIM / PSNR against a master the user names (`qc.reference_video` + `qc.reference_metrics`, ADR-058, [#77](https://github.com/kajisho5/video-production-agent/pull/77)).
